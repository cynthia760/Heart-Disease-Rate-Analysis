# ❤️ Heart Disease Rate Analysis

*By Okeke Onyinye Cynthia*

Healthcare Data Analysis Portfolio Project

---

## 📊 Project Overview

This project analyses heart disease data to identify patterns, risk factors, and demographic characteristics associated with heart disease.

The analysis focuses on transforming healthcare data into clear and meaningful insights using data cleaning, analysis, visualisation, and dashboard reporting.

---

## 🎯 Project Objectives

The main objectives of this analysis were to:

- Analyse the prevalence of heart disease within the dataset
- Identify major risk factors associated with heart disease
- Examine heart disease patterns across different age groups
- Compare heart disease occurrence by gender
- Analyse the relationship between health indicators and heart disease
- Identify high-risk patient groups
- Present findings through an interactive dashboard
- Provide data-driven recommendations based on the analysis

## 🔍 Analysis Process

### 1. Data Preparation
The dataset was reviewed and prepared for analysis to ensure the information was organised and suitable for further exploration.

### 2. Exploratory Data Analysis
The data was analysed to understand the distribution of heart disease and investigate patterns across different patient characteristics and health indicators.

### 3. Risk Factor Analysis
Different variables were compared to determine which characteristics were associated with higher rates of heart disease.

### 4. Data Visualisation
Charts and visualisations were created to make the results easier to interpret and communicate.

### 5. Dashboard Development
An Excel dashboard was developed to summarise the most important findings and provide a clear visual overview of the analysis.
